暮石村 ADV Studio 2.1 — 2D制作環境
=================================

【最初に】
このフォルダーをZIPからすべて展開してください。
原型を改修した編集アプリが Kureishi_ADV_Studio.html です。
プログラミング不要で、文章・背景・表情・選択肢・演出をカードから編集できます。
3D探索ゲーム本体や、未提供の立ち絵・音声を自動制作するものではありません。

【パソコンで開く】
方法1：Kureishi_ADV_Studio.html を Chrome / Edge などのブラウザで開く。
初回は「設定 → バックアップZIPを復元」から starter_backup.zip を選択します。
HTMLを開くアプリがメモ帳になっている場合は、ブラウザのウィンドウへドラッグしてください。

方法2：Python 3 が入っている場合、Windowsは Start_Windows.bat、Macは
Start_Studio.py をPythonで実行します。Mac用 Start_Mac.command も同梱しています。
ブラウザが自動的に開き、同じフォルダーの開始用データを初回だけ読み込みます。
起動用のウィンドウは制作中開いたままにします。終了は Ctrl+C。
この方法は外部ライブラリ不要で、端末内だけで動きます。
毎回同じ起動方法・ブラウザを使ってください。保存先はブラウザとURLごとに別です。

【iPhone / iPadで開く】
「ファイル」アプリのHTMLプレビューは制作アプリを実行するブラウザではありません。
iPhoneで制作する場合は、HTMLを既存のWeb公開先へ置き、そのURLをSafariで開きます。
Kureishi_ADV_Studio.html と starter_backup.zip を同じフォルダーに配置すれば、
初回の開始用データ取り込みは自動です。HTMLだけ置いた場合は手動で復元できます。
今回はオンライン公開URLは発行していません。
実機Safariでのキーボード・音声再生・ダウンロードは未確認です。
画面の狭さに配慮し、入力欄16px、カード操作ボタン、保存状態表示を実装しています。

【一番短い制作手順】
1. シナリオの文章カードをタップ → 下の「編集」。本文を書き換え「保存」。
2. 「＋追加」で背景・人物・音・演出・進行を選ぶ。各項目は選択画面から設定。
3. 「▶再生」で現在のシーンを最初から確認。
4. 「検証」で不足を確認。指摘を押すと該当カードへ移動。
5. 「設定 → 公開用ZIP」でゲームを書き出す。
6. 制作を終える前に「フルバックアップZIP」を端末へ保存。

【背景と会話】
「素材」に背景12枚とUIを登録済みです。背景カードの「素材を選ぶ」で変更できます。
シナリオは添付されたオープニング案の台詞を使った仮稿12シーンです。
最後の13シーン目は、本編外の選択肢・フラグ練習です。
公開前に不要な練習シーンをシーンメニュー「…」で削除してください。
音声は今回の添付にないため登録していません。
日付枠は「現在・昼／夕方／夜」の仮設定です。正確な日付・時間は画面から変更してください。
名前を隠した少女・少年等の台詞は「自由な話者名」で編集できます。

【立ち絵・表情】
添付5枚は人物・画面の設定資料シートとして登録しました。完成立ち絵扱いではありません。
「素材 → 設定画資料 → 切り出し」で人物や表情を個別の素材にできます。
切り出した素材を「キャラ」の8表情に割り当てます。
通常／笑顔／怒り／照れ／悲しみ／驚き／恐怖／真剣の8種類です。
一枚の全身立ち絵を各表情スロットに共用することもできます。
設定画には説明文字や白背景があります。高品質な本編用には個別の透過立ち絵が必要です。

【UI・文字位置】
「UI」で通常・ホラーの会話枠と名前欄を設定済みです。
「位置」または素材の「文字位置を調整」で四辺の余白をドラッグして保存。
この値は同じUI素材を使うすべてのセリフに反映されます。
選択肢4状態はシートから分離して登録済みです。
回想・手紙・侵食・瞬きシートは参考素材のままです。使う箇所を切り出してください。
揺れ・閃光・暗転・名前改変・瞬き差替は「＋追加」から設定できます。
UI画像は表示に不要な透明余白を調整した版を使用しています。元の添付は残しています。

【分岐を作る】
1. 飛び先に「進行 → ラベル」を追加して名前を入力。
2. 「選択肢」を追加し、文章と「飛び先を選ぶ」を設定。
3. 必要なら「フラグ操作」で印を立て、「条件分岐」で印の有無を判定。
シーンをまたぐ場合は飛び先にシーンを選択します。
「シーン終了」は次のシーンへ進みます。最後のシーンならENDになります。

【保存と復元】
ヘッダーに「保存中／保存済／保存失敗」を表示します。
保存失敗が出た場合は、タブを閉じずフルバックアップを作成してください。
自動保存は端末内保存です。クラウド同期ではありません。
別端末ではバックアップZIPを取り込みます。復元は現在のシナリオ・素材を置き換えます。
シナリオJSONには素材は入りません。通常はフルバックアップを使ってください。
素材ID変更・削除・復元はUndoの区切りになります。
使用中素材は削除できません。先にシナリオやキャラ・UIから参照を外します。

【書き出したゲーム】
公開用ZIP：展開して index.html と assets フォルダーを同じ位置に置きます。
単体HTML：使用素材を一つのHTMLへ埋め込みます。素材が12MBを超えると確認を表示します。
公開前の画面で使用素材・未使用素材・容量・検証結果を確認できます。
不足があっても確認して書き出せるので、警告内容を読んでください。
公開用ゲームには編集機能は含まれません。制作再開にはバックアップを使います。

【確認した内容】
Chromiumのスマートフォン相当390×844画面で、復元・カード素材選択・文章編集・
素材ID変更・人物名変更・空行をまたぐカード移動・公開HTML起動・バックアップ再復元・
保存失敗表示・待機中タップ抑止・終了後タイマー停止を確認しました。
開始用プロジェクトの検証指摘は0件。確認時のJavaScript実行エラーは0件です。
iPhone実機、WebKit、実際のBGM/SE再生は未検証です。

【開発を引き継ぐ場合】
元の単一HTML／vanilla JavaScript構成を維持しています。ビルド操作は不要です。
プロジェクトは localStorage kv_proj2、素材は IndexedDB kureishi_studio2 を継続使用。
再生関数 createPlayer(root, project, resolve, options) をHTML内に保持。
3D連携用に options.flags / options.onEnd、adv:flags / adv:end イベント、getState() を追加。
3D側への組み込み自体は、3D本体のソースが今回添付されていないため実施していません。
